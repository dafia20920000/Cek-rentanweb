OWASP Top 10 2023 - Detil Pemeriksaan

Berikut adalah implementasi lengkap pemeriksaan untuk setiap kategori OWASP Top 10:

A01 Injection

Kerentanan yang memungkinkan penyerang mengirimkan data berbahaya ke interpreter.

SQL Injection
OS Command Injection
LDAP Injection
XPath Injection
NoSQL Injection
Metode Pemeriksaan:

1. SQL Injection Testing:

  • Input: ' OR 1=1--
  • Input: admin'--
  • Input: 1; DROP TABLE users
  • Memeriksa error messages yang mengungkap struktur database

2. OS Command Injection Testing:

  • Input: ; ls -la
  • Input: | cat /etc/passwd
  • Input: $(rm -rf /)
  • Memeriksa response time untuk blind command injection

A02 Broken Authentication

Kelemahan dalam mekanisme autentikasi yang memungkinkan penyerang mengkompromikan akun.

Brute Force
Weak Password Policy
Session Fixation
Missing MFA
Exposed Session Tokens
Metode Pemeriksaan:

1. Credential Testing:

  • Mencoba login dengan kredensial default (admin/admin)
  • Menguji kebijakan password (panjang minimum, kompleksitas)
  • Memeriksa proteksi terhadap brute force (rate limiting, lockout)

2. Session Management Testing:

  • Memeriksa regenerasi session ID setelah login
  • Memvalidasi session timeout yang tepat
  • Memeriksa flag HttpOnly dan Secure pada cookies

A03 Sensitive Data Exposure

Gagal melindungi data sensitif seperti informasi pribadi atau kredensial.

Unencrypted Data
Weak Crypto
PII in URLs
Cache Headers Missing
Info in Error Messages
Metode Pemeriksaan:

1. Data Protection Testing:

  • Memeriksa penggunaan HTTPS dan HSTS
  • Memvalidasi algoritma enkripsi (TLS 1.2+, SHA-256+)
  • Mencari data sensitif dalam response (API, HTML comments)

2. Storage Testing:

  • Memeriksa hashing password (bcrypt, Argon2)
  • Memvalidasi penyimpanan data sensitif (CC numbers, tokens)
  • Memeriksa client-side storage (localStorage, sessionStorage)

A10 Insufficient Logging & Monitoring

Kegagalan dalam logging dan monitoring memungkinkan serangan tidak terdeteksi.

Missing Logs
No Alerting
Logs Not Reviewed
No Integrity Checks
Delayed Response
Metode Pemeriksaan:

1. Logging Testing:

  • Memeriksa log aktivitas login yang gagal
  • Memvalidasi pencatatan aktivitas sensitif (ubah password, akses data)
  • Memeriksa format log yang dapat dibaca mesin

2. Monitoring Testing:

  • Memeriksa mekanisme alert untuk aktivitas mencurigakan
  • Memvalidasi response time untuk incident handling
  • Memeriksa integrasi dengan SIEM/SOC
